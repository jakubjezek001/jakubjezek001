# Jakub Ježek

I'm a pipeline engineer in Prague. I lead the editorial, colour and delivery side of [AYON](https://ynput.io/ayon/), the open-source pipeline from Ynput. I have worked on it, and on OpenPype before it, since 2018.

Before that I was a compositor. I did paint and roto at Framestore, then compositing in Nuke and Flame at Czech Television. So most of what I build is for people doing the job I used to do.

**What I work on**

- AYON integrations for Flame and DaVinci Resolve
- [ayon-editorial](https://github.com/ynput/ayon-editorial), one OpenTimelineIO library that the editorial hosts share, so the same code doesn't live in four places
- batch delivery and ingest, which move delivery packaging and transcoding onto the render farm. At three client studios it cut delivery prep time by 89%. I presented it at FMX 2025.
- lately I build with AI agents: Claude Code skills and MCP servers. My [dev workspace](https://github.com/jakubjezek001/Jeza-Ynput-Dev-Workspace) for working on many AYON repositories at once is public.
